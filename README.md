# titanic_project
# Titanic Survival Prediction 🚢

This project uses the famous Titanic dataset to predict survival using Machine Learning.  
It involves **data cleaning, exploratory data analysis (EDA), and model training (Logistic Regression)**.

---

## 📌 Steps in the Project
1. Load the Titanic dataset.
2. Handle missing values (`Age`, `Cabin`, `Embarked`).
3. Encode categorical features (`Sex`, `Embarked`).
4. Perform Exploratory Data Analysis (EDA).
5. Train a Logistic Regression model.
6. Evaluate accuracy.

---

## 📊 Technologies Used
- Python  
- Pandas & NumPy  
- Matplotlib & Seaborn  
- Scikit-learn
